# Security Policy

## Supported Versions

Security fixes are provided for the latest release of the current 4.x line. Older majors and
previous minor releases do not receive patches; upgrade to the latest 4.x release to stay
supported.

| Version | Supported          |
| ------- | ------------------ |
| 4.2.x   | :white_check_mark: |
| < 4.2   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities **privately**. Do not open a public issue, pull request,
or discussion for a security problem, as that discloses it before a fix is available.

- Email: **justin.eiletz@jexcellence.de**
- Include: the affected version, a description of the issue and its impact, and a minimal
  reproduction (or proof of concept) if you have one.

**What to expect:** we aim to acknowledge your report within 3 business days, and to follow up
with an assessment and, where applicable, a remediation plan within 10 business days. We will
keep you informed of progress until the issue is resolved and will credit you in the release
notes unless you prefer to remain anonymous.
